# Changelog

## 1.0.0

Первый релиз / first release.

- Громкость звонка и уведомлений по уровню шума (дБА): подтверждение повышения повторным замером,
  «резинка» при понижении, постоянная автокалибровка по 7 дням (включая ручные проверки).
- Пауза: вибро/без звука, «Не беспокоить», звонок, наушники и Bluetooth, режим автомобиля,
  низкий заряд, воспроизведение звука; ручное изменение громкости — 30 минут без вмешательства.
- По желанию: громкость медиа следует за шумом; повторный звонок после пропущенного — на максимуме
  (тот же или любой номер, окно до 30 минут).
- Чувствительность для звонка и для медиа.
- Root (KernelSU, Magisk, APatch) необязателен: автозапуск после перезагрузки.
- Тема: системная/светлая/тёмная, чёрный фон, системный или свой акцент. Русский и английский.
- Обновления из GitHub Releases внутри приложения.
